# Kommentar till skattebrottslagen (1971:69)

Kommentar till svensk författning: **Skattebrottslag (1971:69)** (SFS 1971:69). Kommentaren omfattar **23 enheter** (22 paragrafer, 1–17 §§ inklusive 13 a, 13 b, 14 a, 14 b och 14 c §§ samt den upphävda 9 §, och övergångsbestämmelserna) fördelade på 2 kommentarskapitel; vid varje enhet återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2026:1531** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2026-09-10).

Källa: [rkrattsbaser.gov.se/sfst?bet=1971:69](https://rkrattsbaser.gov.se/sfst?bet=1971%3A69) · [data.riksdagen.se/dokument/sfs-1971-69](https://data.riksdagen.se/dokument/sfs-1971-69.json)
